# Ari Lyrics — Native 1.7.8

## Скиллы для работы над проектом

- [ari-lyrics-mpris](skills/ari-lyrics-mpris/SKILL.md) — MPRIS, часы воспроизведения, LRC и смена песни.
- [ari-lyrics-noctalia](skills/ari-lyrics-noctalia/SKILL.md) — сборка, тесты, runtime Noctalia и fullscreen Hyprland.

Скиллы хранятся в `skills/`. Для использования в текущем чате укажи путь,
например: «Используй `skills/ari-lyrics-mpris/SKILL.md` и исправь скачки текста».
Для автоматического обнаружения Codex скопируй нужные каталоги в
`.agents/skills/` проекта либо `~/.codex/skills/`; после обнаружения их можно
вызывать как `$ari-lyrics-mpris` и `$ari-lyrics-noctalia`.

Компактный модуль текста песен для Noctalia 5 / Hyprland.
C++20 / Qt6 Core, DBus, Network обрабатывает MPRIS, часы воспроизведения,
LRC, поиск LRCLIB, MusicBrainz, Lyrics.ovh и дисковый кеш.
Luau адаптирует данные к штатному API24 сервиса и окон Noctalia.

## Поведение

- Источник — Wave (MPRIS DesktopEntry `wave` и Identity `Wave`) или YouTube Music: точный домен music.youtube.com или
  известное настольное приложение YouTube Music с MPRIS-интеграцией.
  Обычные youtube.com / youtu.be в браузере исключаются даже при музыкальном имени плеера.
  Из Wave принимаются локальные/скачанные песни и выбранные YouTube-аудиопотоки.
  Нужна версия Wave с Linux MPRIS; URL аудиопотока модулю не передаётся.
- Виджет занимает место часов в центре верхнего бара. При воспроизведении
  раскрывается за 2,2 секунды: текущая строка текста или название и исполнитель
  слева, цельное время `17:00` на мягкой приглушённой подложке справа.
  Ширина раскрытого модуля — 380 px.
  При сворачивании часы возвращаются в центр.
  При паузе сохраняет текст до 5 минут, затем возвращает часы.
  При исчезновении источника часы возвращаются без ожидания. Возобновление
  сбрасывает таймер. Капсула плавно меняет ширину, текст затухает с неподвижной
  базовой линией; частые обновления позиции не перезапускают переход.
- Клик по музыке раскрывает плеер: обложка, название, исполнитель, время,
  прогресс, управление, спектр и текущая строка. Кнопки ведут к полному тексту
  и поиску и расположены по краям ряда переключения треков и паузы.
  Под плеером видны предыдущая, текущая и следующая строки LRC:
  текущая яркая в центре, соседние приглушены. При переходе следующая строка
  плавно поднимается на место текущей и становится ярче;
  новые песни и перемотка сразу показывают актуальный текст без старого превью.
  Клик по часам открывает меню Noctalia (Control Center). Старой автоматической карточки
  под баром больше нет. Виджет часов заменяется только в `bar.main.center`.
- Аудиоспектр — отдельный C++/PipeWire процесс, FFT 2048 отсчёта,
  32 логарифмические частотные полосы, зеркально отображаемые 64 столбиками,
  50 обновлений в секунду. Столбики растут вниз непосредственно от прогресса
  под временем трека; низкие частоты сходятся в центре. Рисование штатными
  элементами Noctalia, без Canvas и внешнего визуализатора. Захватывается
  текущий аудиовыход целиком, включая другие приложения, не микрофон.
  При паузе и закрытии панели захват прекращается; просроченный lease
  отключает его даже при пропавшем интерфейсе. Без PipeWire остаётся обычный
  плеер. Обложки MPRIS загружаются асинхронно в отдельный кеш.
  Захват просыпается по изменению lease-файла, без ожидания очередного опроса.
  Повторное открытие сбрасывает старый таймер подключения; сглаживание быстрее
  реагирует на удар и спад. Пауза/закрытие по-прежнему отключают захват.
- Нативные сокеты Hyprland отслеживают fullscreen текущего рабочего стола.
  Учитывается также полноэкранное активное окно дополнительного рабочего стола.
  Эти поля доступны в JSON; видимость верхнего бара управляется самой Noctalia.
- MPRIS Position интерполируется по Rate только после подтверждённой позиции.
  Неизменное значение при Playing не считается остановкой часов.
  Seeked меняет позицию сразу, вместе с актуальными метаданными песни.
  Пауза замораживает часы; продолжение и смена скорости сохраняют позицию.
  Временная потеря длительности/Position для той же песни не сбрасывает часы.
- Плагин не ставит музыку на паузу для автоматического восстановления таймера.
  При отсутствии и Position, и Seeked у новой песни показывается обычный текст
  с явным сообщением о недоступном времени.
  «Восстановить время» в окне текста / значок обновления в поиске — явное
  ручное действие: короткая пауза 0.3 с и продолжение для сбоя Firefox.
- Строки меняются через косинусное затухание без движения базовой линии.
  Кадровые обновления работают только во время перехода.

## Поиск текста

Mod+Y — окно текста; Mod+Shift+Y / кнопка поиска — поиск текста внутри плагина.
Исходный запрос заполняется названием и исполнителем текущей песни.
Результаты загружаются из LRCLIB, включая текст и временные метки.
Сначала показываются совпадения названия, исполнителя и длительности,
предпочтительно с LRC. Ранжирование выполняется до ограничения 30 результатами;
предусмотрен дополнительный поиск с явными полями track_name / artist_name.

Клик по записи открывает предварительный просмотр: подходящий LRC сразу
следует за текущей позицией песни. «Показывать этот текст» закрепляет выбор
за этой песней и закрывает поиск. Музыка продолжает играть с прежнего места.
«Автопоиск» сбрасывает ручной выбор. Внешние страницы для получения текста
не открываются. Результаты и обычный длинный текст разбиты на страницы
для соблюдения размеров окна Noctalia API24.

При несовпадении длительности более чем на 3 секунды выбранный вручную текст
показывается без синхронизации. Если источник предоставляет только текст без
временных меток, подсветка по времени недоступна. При смене песни незавершённый
поиск не применяется к новой песне. «Раньше» / «Позже» в окне текста меняют
поправку на 0.25 секунды для конкретной песни.

Автопоиск сначала использует LRCLIB /api/get, затем /api/search.
Обычный текст из /api/get или кеша не мешает дополнительному поиску LRC.
Название/исполнитель нормализуются по Unicode NFKC; учитываются японские
пробелы и суффикс YouTube «- Topic». Известная длительность должна совпадать
в пределах 3 секунд. MusicBrainz уточняет метаданные только при совпадении
названия, исполнителя и длительности; запросы ограничены одним за 1.1 секунды.
Lyrics.ovh — резерв обычного текста. Распознавания по звуку нет.

## Сборка и установка

~~~sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
ctest --test-dir build --output-on-failure
python3 tools/install-island.py --build-dir build --dry-run
python3 tools/install-island.py --build-dir build
~~~

Установщик сохраняет резервные копии runtime и конфига, проверяет manifest
и TOML, устанавливает плагин и заменяет `clock` на `ari_lyrics` в центре
основного бара. Остальные виджеты сохраняются. `--dry-run` показывает изменение
конфига без записи. Для установки отдельно от настройки бара доступен
`cmake --install build --prefix "$HOME/.local/share/noctalia/plugins/ari-lyrics"`.
Luau-исходники теперь хранятся в `runtime/` и устанавливаются вместе с C++.
Архивы runtime лежат в соседнем с `plugins/` каталоге `plugin-backups/`,
чтобы их manifest не обнаруживался как ещё одна копия плагина. Резервные
копии предыдущего установщика с именем `ari-lyrics.before-island-<timestamp>`
переносятся туда при обновлении с сохранением содержимого.
Капсула и её область наведения принадлежат Noctalia; вложенный фон не
рисуется. Панель закрепляется под центром бара, привязка к точке клика
выключается и сохраняется в конфиге. Позиционные обновления не пересоздают
неизменившийся текст; полное окно сохраняет раскладку текста во время
штатной анимации открытия/закрытия.

Для сохранения ранее выбранного пользователем доступа Codex на запись
к `/` между запусками установщик поддерживает явный дополнительный флаг:
`python3 tools/install-island.py --build-dir build --persist-codex-permissions`.
Он сохраняет резервную копию конфигурации Codex и записывает
`sandbox_mode = "workspace-write"` и `sandbox_workspace_write.writable_roots = ["/"]`.
Без флага настройки Codex не меняются. `--dry-run` с этим флагом показывает
оба изменения. Настройки относятся к будущим запускам CLI и не отменяют
ограничения управляющей среды. При использовании `default_permissions`
установщик требует отдельной настройки именованного профиля вместо смешения
двух схем. Параметры описаны в [официальной документации Codex](https://learn.chatgpt.com/docs/config-file/config-reference).

Runtime: `~/.local/share/noctalia/plugins/ari-lyrics/`.
Один C++ процесс обслуживает все окна, получает SIGTERM при выгрузке сервиса.
Зависимости: CMake, C++20, Qt6 Core/DBus/Network, playerctl, Noctalia API24+.
Для нативного спектра нужны pkg-config и libpipewire-0.3; без них CMake
собирает плеер без спектра. Для установщика нужен Python 3.11+.
HTTP-запросы асинхронны, ограничены 12 секундами и 2 МиБ; TLS проверяется.

## Данные и диагностика

- Кеш: ~/.cache/ari-lyrics/tracks/ (SHA-256 по названию/исполнителю/альбому/длине).
- Обложки: ~/.cache/ari-lyrics/art/; lease спектра: $XDG_RUNTIME_DIR/ari-lyrics/.
- Выбранные тексты: ~/.config/ari-lyrics/overrides/<trackId>.json.
- Поправки времени: ~/.config/ari-lyrics/offsets.json, атомарная запись с блокировкой.
- CLI: --snapshot; --search QUERY [--title TITLE --artist ARTIST --duration SECONDS];
  --choose-lyrics TRACK_ID LRCLIB_ID; --clear-lyrics TRACK_ID;
  --adjust-offset TRACK_ID SECONDS.
- Поток JSON: источник, позиция, скорость, строки, источник текста/ID записи,
  musicEligible, fullscreenKnown, fullscreen и локальный artPath. Первый --snapshot может быть
  сделан до ответа сокетов Hyprland или завершения загрузки слов.

## Проверки

lyrics-core: LRC / Unicode / offset / seek, консервативное совпадение песни,
фильтр домена и настольного приложения, статический MPRIS Position, пауза,
продолжение, Rate, Seeked со старым свойством Position, fullscreen/maximized,
ранжирование подходящих записей до усечения выдачи.

mpris-integration: отдельная D-Bus сессия, тестовые сокеты Hyprland,
оригинальные строки из кеша; смена песни, выбор текста, сдвиг, перемотка,
пауза, статический Position больше 2.5 с, fullscreen с паузой/перемоткой,
максимизация, обычное YouTube-видео, честное отсутствие времени и новый
трек с Seeked до следующего опроса. Реальные приложения и интернет не используются.

CTest также запускает `spectrum-core` (частоты, тишина, нечисловые входы),
`artwork-core` (локальные обложки, очистка при смене источника),
а при наличии Lua — проверки `ui-island`, `ui-widget`, `ui-player`, `ui-panel`, `ui-search`, `ui-motion`, `ui-lyric-scroll`.
Проверки Luau можно запустить из `runtime/`: `lua verify-island.lua`,
`lua verify-player.lua`, `lua verify-search.lua`, `lua verify-motion.lua`.
Установщик проверяется через `python3 tests/install-tests.py`.
`spectrum-stream` проверяет быстрый повторный запуск выдачи кадров и обновление
lease без прерывания захвата, с изолированным недоступным аудиосервером.
`spectrum-restart` проверяет повторное подключение на отдельном тестовом Unix-сокете;
при запрете таких сокетов средой эта проверка явно пропускается.
`noctalia plugins lint runtime` проверяет manifest, пути к файлам и настройки.

В среде, запрещающей Unix-сокеты и D-Bus, исходные `lyrics-core` и
`mpris-integration` могут завершиться ошибкой окружения. Это не заменяет
проверку установленного плагина в живой сессии Noctalia.
